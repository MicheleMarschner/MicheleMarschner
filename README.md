I'm currently finishing my Master's in Computational Science, although my path started in business administration. Along the way, I've also worked on an entrepreneurial project and taught programming, giving me the chance to experience both the business and technical sides of things.

## 🔭 What I'm Currently Exploring

### Master's Thesis — Explainable AI & Object Detection

**Which visual concepts do deep learning (DL) models rely on for object detection — and how does their relevance change under domain shift?**

For my Master's thesis, in collaboration with Fraunhofer HHI, I'm investigating this question using YOLOv8 and Colorado potato beetle detection as a case study. I'm applying concept-based explainability methods (L-CRP and PCX) to analyze which concepts contribute to detections and how their relevance changes across domains.

## 💻 Selected Projects

Here are a few projects I've worked on:

### [TicketForVisa – Booking Web Application](https://github.com/MicheleMarschner/ticketforvisa-showcase)

A production web application I developed for a client, combining multi-step booking, payment processing, and automated notifications. Beyond the user-facing application, the work involved handling failures across external services, deciding what data to retain for recovery, and balancing reliability with the constraints of an MVP.

*Live application · Technical case study (source code is private)*

### [Jaguar Re-Identification](https://github.com/MicheleMarschner/jaguar_project)

A two-person university project for the Kaggle Jaguar Re-ID challenge, exploring how deep learning models can identify individual jaguars across different images. I worked on data preparation, extending the experimental pipeline, and investigating potential shortcuts through background interventions, foreground analysis, and explainability experiments.

### [BeyondLiteral – Multilingual Idiomaticity Detection](https://github.com/MicheleMarschner/BeyondLiteral_Idiomaticity_Detection_ANLP_Project)

How can a model distinguish between literal and idiomatic expressions across different languages? In this university team project, we explored the question using lexical baselines and transformer models, investigating context use and cross-lingual transfer. My work focused on building the experimental pipeline, implementing baselines, and evaluating model behavior.
